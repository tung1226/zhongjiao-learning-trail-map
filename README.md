# 中角國小學習步道地圖｜原版動畫＋30學道連結

本版本依照您的要求：

1. 保留最初版本的開場動畫：`assets/將以上圖片變成一個短動畫.mp4`
2. 保留最初版本的校園平面圖：`assets/中角學習步道圖(文字).jpg`
3. 不更動原本的網站版型與互動方式
4. 將 1～30 個學習步道全部加入對應的 Google Sites 連結

## GitHub Pages 部署
1. 解壓縮本 ZIP。
2. 建立 GitHub Repository。
3. 把解壓縮後「資料夾內的所有檔案」上傳到 Repository 根目錄。
4. 到 Settings → Pages。
5. Source 選 `Deploy from a branch`。
6. Branch 選 `main`，Folder 選 `/(root)`。
7. 儲存後等待 GitHub Pages 產生網址。

## 主要檔案
- `index.html`：網站入口
- `style.css`：網站樣式
- `script.js`：互動功能
- `trail-data.js`：30 個學道名稱、座標與 Google Sites 網址
- `position-editor.html`：學道號碼位置調整工具
- `assets/將以上圖片變成一個短動畫.mp4`：原版開場動畫
- `assets/中角學習步道圖(文字).jpg`：原版平面圖
